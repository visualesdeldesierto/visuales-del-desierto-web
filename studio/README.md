# Studio de contenido

Este Studio administra los proyectos que aparecen en la portada.

- Proyecto: `ud3wwp5r`
- Dataset: `production`
- Tipo de contenido: `Proyecto`

## Uso local

```powershell
npm install
npm run dev
```

Para que un proyecto aparezca en el sitio, completa nombre, categoría e identificador web; agrega una imagen principal con descripción accesible; activa **Publicar en el sitio** y publica el documento.

El sitio muestra hasta seis proyectos. Los destacados aparecen primero y después se respeta el campo **Orden**.
